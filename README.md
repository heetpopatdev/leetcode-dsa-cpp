# LeetCode DSA in C++

My journey of learning Data Structures and Algorithms using C++ and solving LeetCode problems.

Build strong problem-solving and DSA fundamentals for software engineering interviews.

## 🧠 Problem-Solving Rule

For every problem:

1. Understand the problem
2. Think about the brute-force solution
3. Write the solution
4. Test with examples
5. Analyze time complexity
6. Analyze space complexity
7. Write clean C++ code
8. Commit the solution to GitHub
