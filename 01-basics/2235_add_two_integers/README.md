# LeetCode 2235 - Add Two Integers

## Problem

Given two integers `num1` and `num2`, return their sum.

## Example

Input:

`num1 = 12, num2 = 5`

Output:

`17`

Process:

`12 + 5 = 17`

## My Approach

1. Take two integers as parameters.
2. Add `num1` and `num2`.
3. Return the result.

## Key Concepts

- Functions
- Parameters
- Return statement
- Addition operator `+`

## Time Complexity

O(1)

Only one addition operation is performed.

## Space Complexity

O(1)

No additional data structure is used.

## What I Learned

A function can take two values as parameters, perform an operation, and return the result.
